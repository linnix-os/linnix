# CLA signatures

Written by the CLA Assistant workflow (`.github/workflows/cla.yml` on `main`).
`signatures/version1/cla.json` records each contributor's GitHub username, ID,
pull request and signing time for version 1.0 of [CLA.md](https://github.com/linnix-os/linnix/blob/main/CLA.md).

Do not edit by hand, and do not merge this branch into `main`.
